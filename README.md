Entry for the [make.fun](https://make.fun) competition
**Everyday Things, Two Lines, Longer Run** (`u-suga-everyday-things-two-lines-longer-run-f8734479`).

The program writes two lines to `/output/entry.txt`: line 1 explains a
shadow to a 10-year-old in one vivid sentence built on an analogy, and
line 2 says in one sentence what the analogy maps and what it leaves out.

Run it:

```sh
node main.ts
cat /output/entry.txt
```
